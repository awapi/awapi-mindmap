# User Guide

## Opening a mind map

Use **File › Open…** (`⌘O` / `Ctrl+O`) to open a `.awmm` file.

## Creating a new mind map

Use **File › New Map** (`⌘N` / `Ctrl+N`). A blank canvas with a single "Central Topic" node is created.

## Editing nodes

- **Double-click** a node to rename it.
- **Drag** a node to reposition it.
- **Connect** nodes by dragging from a node handle to another node.

## Saving

- **File › Save** (`⌘S` / `Ctrl+S`) — saves to the current file, or prompts for a path on first save.
- **File › Save As…** (`⌘⇧S` / `Ctrl+Shift+S`) — always prompts for a new path.

Files are saved in the `.awmm` format (JSON).

## Theme

Toggle dark / light mode from the **View** menu (coming soon).
